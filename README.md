# WageTicker(リアルタイム給料メーター)

`SPEC.md` の実装。フレームワーク・外部ライブラリ・ビルド不要の HTML + JavaScript 単体構成です。

## 使い方

`index.html` をブラウザで開くだけで動きます(`file://` のままで可)。初回は設定画面が開くので、基本給と働き方を登録してください。

スマホの実機で確認したいときは、同じ Wi-Fi 上で簡易サーバーを立てられます(開発用・依存なし)。

```powershell
pwsh -File serve.ps1 -Any       # 表示された http://<PCのIP>:8765/ をスマホで開く
```

データはサーバーへ送信されず、その端末のブラウザの localStorage にのみ保存されます(SPEC 12)。

## テスト

Node もインストールも不要です。2 種類あります。

```powershell
pwsh -File test\run.ps1     # 全部まとめて実行(100件)
```

| スイート | 件数 | 内容 |
|---|---|---|
| `test/tests.js` | 50 | 給与計算の純粋関数(SPEC 3〜8章)。締め日、休憩控除、深夜、区分と割増、有給・半休・未入力日、前月比較、固定残業代、週集計、残業メーター、ロールオーバー |
| `test/holidays.js` | 13 | `src/holidays.js` の国民の祝日計算。固定日・移動祝日・春分秋分・振替休日・国民の休日・過去の例外年 |
| `test/smoke.js` | 37 | `src/app.js` を DOM の代役の上で起動し、出勤→描画→内訳→退勤、自動モード、カレンダーからの追記・休憩編集、テーマ切替、保存までを通しで確認 |

`test/index.html` をブラウザで開くと、`test/tests.js` と `test/holidays.js`(あわせて58件)がその場で走ります。

`test/run.ps1` は Windows 同梱の Windows Script Host(cscript)で JavaScript を実行しています。そのエンジンは ES3 相当なので、`test/es3-shim.js` で不足分を補い、`test/dom-stub.js` で最小限の DOM を用意しています。いずれもテスト専用で、アプリ本体には含まれません。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格(メイン3数値・2ボタン・折りたたみ補助情報・設定/カレンダーのシート) |
| `styles.css` | LCD/計器盤モチーフ。外部フォントなし |
| `src/constants.js` | 割増率・深夜帯・36協定の目安・デフォルト設定値の一元管理 |
| `src/time.js` | 日付/時刻ユーティリティ。深夜帯の分割、休憩帯の差し引き |
| `src/period.js` | 賃金締め日から清算期間を算出 |
| `src/holidays.js` | 国民の祝日の算出(固定日・移動祝日・春分秋分・振替休日・国民の休日) |
| `src/wage.js` | 基礎時給単価、休憩控除、所定内/法定内残業/法定時間外/深夜/法定休日/固定残業代の区分計算 |
| `src/aggregate.js` | 清算期間の集計、有給・会社休日・未入力日、前月比較、残業メーターの見え方 |
| `src/storage.js` | localStorage、締め日のロールオーバー、自動モードの状態解決 |
| `src/app.js` | DOM 層(描画ループ・打刻操作・設定/カレンダー UI) |

`src/app.js` 以外は DOM に触れない純粋関数の層です(SPEC 14)。区分計算は 1 秒ごと、描画は `requestAnimationFrame` で分離しています。

## SPEC からの判断・補足

計算精度(SPEC 1.1「計算は極力正確に」)を優先して、次の 4 点は仕様の字面より実態に寄せています。いずれも定数か関数 1 つで元に戻せます。

1. **休憩の自動控除は「実際に重なった分」**(`wage.js: sessionWork`)
   SPEC 5.2 の字面は「重なっていればその時間帯の長さ」ですが、13:00 出勤で 12:00〜13:00 の休憩帯にわずかに掛かる日などで過剰控除になるため、実際の重複時間だけを差し引きます。まるごと重なる通常の日は仕様どおり 60 分控除になります。

2. **休憩時間帯が未登録のときの一律 60 分は、実働 8 時間かけて按分**(`wage.js: flatBreakDeduction`)
   出勤直後から 60 分をまとめて引くと、朝いちばんの実働・金額がマイナスになり「開いた瞬間に増えている」という体験(SPEC 1.1)が壊れます。8 時間以上働けば控除はちょうど 60 分になり、SPEC 5.2 と一致します。按分幅は `constants.js: FLAT_BREAK_RAMP_MINUTES`。

3. **法定休日労働は所定/法定の総枠・月 60 時間ラインに算入しない**(`wage.js: allocateSegments`)
   SPEC 5.4 の擬似コードは「区分計算後に 1.35 倍へ置き換える」ですが、労基法上、法定休日労働は時間外労働に算入しません。算入すると平日の残業区分まで押し上がってしまうため、独立した区分として扱っています。金額は SPEC 3.3 の表(1.35 / 深夜と重なれば 1.60)どおりです。

4. **設定に「所定労働日の曜日」を追加**
   所定労働時間の総枠には清算期間内の所定労働日数が必要で(SPEC 3.2)、毎月カレンダーで指定させるのは「操作は単純に」に反します。法定休日の曜日から週休二日を既定値として自動生成し、設定画面で変更できるようにしました。自動モードの「勤務予定の曜日」(SPEC 4)と共用しています。

5. **1日の所定労働時間は入力せず、勤務時間 − 休憩時間で自動算出**(`wage.js: deriveDailyScheduledHours`)
   基本給・勤務時間・休憩時間を入れれば所定労働時間は決まるため、入力項目をひとつ減らしました。設定画面には自動計算の結果を表示します。

6. **覗き見防止のぼかしを廃止**
   SPEC 11 の機能ですが、増えていく数字が見えないとモチベーションにならない(SPEC 1.1 の目的に反する)という判断で削除しました。設定画面の基本給欄の伏せ字だけは残しています。

7. **勤務間インターバルの目安を廃止**(SPEC 8.2 ②)
   設定項目と表示の両方を削除しました。休憩未取得の目安(8.2 ①)は残しています。

8. **見た目をカード基調の計器ダッシュボードにし、ライト/ダーク切替を追加**
   提示されたデザイン見本に合わせています。既定は端末の設定に追従し、ヘッダーのボタンで明示的に切り替えられます。

9. **固定残業代(みなし残業)に対応**(`wage.js: allocateSegments`)
   SPEC には無い項目です。設定した時間までは追加の割増を付けず、超えた分から通常どおり1.25(月60時間超は1.50)倍を上乗せします。60時間ラインへの算入や、固定残業代が法律上の最低額を下回っていないかの参考チェックも行います。

10. **国民の祝日を所定労働日から自動的に除外**(`src/holidays.js`)
    SPEC には無い項目です。固定日・移動祝日(第◯月曜日)・春分/秋分・振替休日・国民の休日(祝日に挟まれた日)を計算し、既定でオンにしています。設定でオフにでき、個別の日は会社休日の指定が常に優先されます。

11. **半休(半日有給)に対応**(`wage.js: allocateHalfDay`)
    SPEC には無い項目です。設定した区切り時刻(既定13:00)を境に、午前休/午後休のどちらかを有給扱い、残り半分を標準勤務スケジュールどおりの実勤務として計算します。半日ぶんの勤務のため、昼休憩は控除しません。カレンダーから指定します。

そのほか補足:

- 残業時間の目安(参考表示)は、月45時間(36協定の原則上限)・月60時間(割増率が変わるライン)・単月100時間(休日労働を含む、特別条項があっても超えられない上限)を、今月ぶんの時間だけで表示しています。複数月平均や年間の集計は行っていません。
- 時間外労働の端数処理(30分未満切り捨て等)は SPEC 9 のとおり適用せず、実数のまま積算します。
- ES モジュールではなく素の `<script>` 分割にしてあるのは、`file://` から直接開いても動くようにするためです。
