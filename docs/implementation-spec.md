## 1. 概要

月給制・フレックスタイム制(コアタイムなし)の従業員向けに、**出勤するだけで金額と労働時間が
秒単位で積み上がっていく** のを見せるWebアプリ。目的は、増えていく数字を見て働くモチベーションを
高めること。

設計三原則:

- **計算は極力正確に** — 就業規則・労基法に照らした区分計算を裏側で行う
- **操作は単純に** — 平常時のボタンは「出勤 / 退勤」の2つだけ。自動モードならゼロ
- **表示はシンプルに** — 常時見えている数字は3つだけ

サーバーを持たず、データは端末のブラウザ内(localStorage)にのみ保存する。

## 2. 画面

### 2.1 メイン画面

上から順に、次の要素だけを常時表示する。

カード基調の計器ダッシュボード。上から順に次を積む。

| 位置 | 要素 | 内容 |
|---|---|---|
| ヘッダーカード | アプリ名・状態バッジ・テーマ切替 | 待機中 / 勤務中 / 自動計測中 / 休憩中 |
| 最優先 | **① 今このセッション** | 半円ゲージ(今日の実働)+ 秒単位で増える金額(小数2桁)+ いまの区分と倍率 |
| 同じカードの右 | 今月の縦バー | 今月の実働を、所定・法定の2つの総枠の目印と並べて示す |
| 同列3枚 | **② 今日** / **③ 今月** / 先月比 | 金額・実働時間・先月同時点との差 |
| 折りたたみ | 内訳と目安 | 既定は閉じている(2.2) |
| 画面下に固定 | 操作バー | 出勤 / 退勤(自動モード時は残業開始 / 残業終了)、カレンダー、設定 |

差し色は、いま加算されている区分によって静かに変わる(ゲージ・金額の下のラベル・縦バー)。
警告色・通知音は使わない。

| 区分 | 色 |
|---|---|
| 所定内 | シアン |
| 法定内残業 | ブルー |
| 法定時間外(1.25 / 1.50) | アンバー |
| 深夜(22:00〜翌5:00) | バイオレット |
| 法定休日 | ピンク |
| 休憩中(カウント停止) | グレー |

出勤していないときは、その日の直近の勤務ぶんを静かに表示する。

### 2.1.1 ライト / ダーク

既定は端末の設定に追従する。ヘッダーのボタンで明示的に切り替えられ、選択は
`wageTheme` に保存される。色はすべて CSS のトークンで定義しており、
コンポーネント側に生の色を書かない。

### 2.2 折りたたみの補助情報

- **今月の内訳** — 所定内 / 法定内残業 / 法定時間外(1.25・1.50)/ 法定休日 / 深夜割増 / うち未入力の自動加算 / 基本給とは別の追加分
- **賃金の計算式** — 所定労働時間・月平均所定労働時間・基礎時給単価を、実際の数値を入れた式で示す(4.1)
- **清算期間** — 対象期間、締め日まであと何日か(速報値である旨)、所定労働日数と総枠、法定労働時間の総枠、先月同時点の実績と差
- **36協定の目安** — 今月の法定時間外、45時間・60時間までの残り、直近12ヶ月の累計、月45時間超の回数、直近2〜6ヶ月平均
- **気づき** — 休憩未取得の目安
- **未入力の日** — 何日あるか、どの日か(催促や警告の体裁にはしない)
- **先月(確定)** — 前清算期間の合計

### 2.3 設定画面

4章の項目に加え、「データの保存とリセットについて」「この数字について(免責)」の説明を
折りたたみで常設する。最下部に「すべてのデータを消す」(誤操作防止のため2回押し)。

### 2.4 カレンダー画面

月ごとのマス目。**週は月曜始まり**。マスの色点で状態を示す。

| 色点 | 意味 |
|---|---|
| 緑 | 打刻あり(出勤した日) |
| 水色 | 有給休暇 |
| 紫 | 法定休日 |
| グレー | 所定休日(法定超) |
| 琥珀 | 未入力(所定内として自動加算されている日) |

マスをタップすると、その日を「指定なし / 出勤 / 有給 / 会社休日」に変更できる。出勤を選んだ
場合は時刻を入力でき(翌日にまたがる指定も可)、法定休日として扱うかも選べる。

## 3. 設定項目

上から「基本給 → 勤務時間 → 休憩時間」の順に並べ、**その3つから1日の所定労働時間が決まる**。
そのあとに曜日、年間休日、締め日と続く。

| 順 | 項目 | 既定値 | 入力方法 |
|---|---|---|---|
| 1 | 基本給(月額) | 未設定(例として 300,000 を表示) | 入力欄・マスク表示(「表示」ボタンで確認) |
| 2 | 出勤時間 / 退勤時間 | 9:00〜17:30 | プルダウン(15分刻み) |
| 3 | 休憩時間帯 | 12:00〜13:00 | プルダウン(15分刻み)/「登録しない」も選べる。**開始を選ぶと終了は1時間後が入る** |
| — | 1日の所定労働時間 | 7時間30分 | **自動計算(入力しない)**。勤務時間 − 休憩時間 |
| 4 | 所定労働日の曜日 | 月〜金 | 曜日ボタン(日曜始まり・複数選択) |
| 5 | 法定休日の曜日 | 日曜日 | プルダウン(日曜始まり) |
| 6 | 年間所定休日数 | 120日 | プルダウン(90〜145日) |
| 7 | 賃金締め日 | 末日 | プルダウン(末日 / 1〜31日) |
| 8 | 自動モード | オフ | チェック |

出勤時間・退勤時間は自動モード専用ではなく、カレンダーから打刻を追記するときの初期値にも使う。

既定値の根拠: 厚生労働省「就労条件総合調査」(企業規模1,000人以上)で1日の所定労働時間は
おおむね7時間43分〜7時間47分。覚えやすい値として7時間30分を採用した。年間休日は同調査の
実態値(116.6日)と一般的な案内(120〜125日)の中間として120日とした。

保存済みの設定値がプルダウンの選択肢に無い場合(例: 7.6時間)は、その値を選択肢に足してから
選ぶため、設定が勝手に変わることはない。

## 4. 計算仕様

### 4.1 基礎時給単価

```
1日の所定労働時間 = (退勤 − 出勤) − 勤務時間と重なる休憩
                    ※ 休憩時間帯が未登録なら一律60分
年間所定労働日数   = 365 − 年間所定休日数           (うるう年も365固定)
月平均所定労働時間 = 年間所定労働日数 × 1日の所定労働時間 ÷ 12
基礎時給単価       = 基本給 ÷ 月平均所定労働時間
```

この式は、設定画面(所定労働時間の欄)と、折りたたみの「賃金の計算式」に
実際の数値を入れた形で表示する。

既定値の場合: 年間245日 → 月平均153.125時間 → 基本給30万円なら **1,959円/時**。

端数処理は行わず、実数のまま積算する。

### 4.2 清算期間

賃金締め日を基準に、締め日の翌日から次の締め日までを1つの期間とする。

- 締め日が「末日」なら、その月の1日〜末日
- 締め日が20日なら、前月21日〜当月20日
- 31日締めで2月のように短い月は、その月の末日に丸める
- 期間ラベルは **期間末の年月**(8/21〜9/20 は「2026-09」)

### 4.3 所定労働日と2つの総枠

**所定労働日** = 会社休日に指定されておらず、かつ「所定労働日の曜日」に含まれる日。

```
所定労働時間の総枠 = 1日の所定労働時間 × 清算期間内の所定労働日数
法定労働時間の総枠 = 40時間 × 清算期間の暦日数 ÷ 7
```

フレックスタイム制(コアタイムなし)のため、**1日8時間超・週40時間超という日次/週次の
残業判定は行わない**。清算期間の累計実働時間を、期間の頭から順に次の順で消化していく。

```
① 所定内労働        … 所定労働時間の総枠に収まる分
② 法定内残業        … 所定の総枠は超えたが、法定の総枠には収まる分
③ 法定時間外労働    … 法定の総枠も超えた分(月60時間を境に倍率が変わる)
```

### 4.4 割増率

| 区分 | 倍率 | 深夜と重なる場合 |
|---|---|---|
| 所定内労働 | 1.00(基本給に含まれる分の取り崩し) | 1.25 |
| 法定内残業(所定超・法定内) | 1.00 | 1.25 |
| 法定時間外労働(月60時間まで) | 1.25 | 1.50 |
| 法定時間外労働(月60時間超) | 1.50 | 1.75 |
| 法定休日労働 | 1.35 | 1.60 |

- 深夜(22:00〜翌5:00)は、他の割増に **+0.25** を加算する
- 所定内労働は法的には追加支払いのない区分だが、画面には基本給の日割り取り崩しとして
  1.00 で積み上げる。「基本給とは別の追加分」は内訳で別に示す
- **法定休日労働は、所定/法定の総枠にも月60時間ラインにも算入しない**(労基法上、休日労働は
  時間外労働に算入しないため)
- 所定休日(法定超・例: 土曜)の出勤は35%増にはせず、通常の①②③の枠組みで計算する

倍率はすべて `src/constants.js` の `RATE` に集約してある。就業規則が法定を上回る場合は
そこだけを書き換えればよい。

### 4.5 休憩の自動控除

休憩は打刻しない。次のどちらかで自動的に差し引く。

**休憩時間帯を登録している場合**(既定 12:00〜13:00)

打刻区間と重なった分だけを控除する。重ならない日(午前半休で13:00から出勤など)は控除が
発生しない。休憩時間帯に入っているあいだはカウンターが止まる。

**登録していない場合**

一律60分を、実働8時間かけて滑らかに引き切る。

```
控除分 = 60分 × min(1, 実働の経過分 ÷ 480分)
```

8時間以上働けば控除はちょうど60分になる。出勤直後に60分をまとめて引くと金額がマイナスから
始まってしまうため、この方式にしている。

### 4.6 深夜労働

22:00〜翌5:00。打刻区間を深夜/非深夜に切り分け、深夜に重なる分だけ +0.25 を加算する。
日をまたぐ勤務にも対応する。

### 4.7 有給休暇・会社休日・未入力日

| 種別 | 扱い |
|---|---|
| 有給休暇 | 打刻なしで1日の所定労働時間分を「所定内」として計上。時間外・深夜・休日の割増対象にはしない |
| 会社休日 | その日を所定労働日から除外する。未入力日にもしない。指定時に「法定休日」か「所定休日(法定超)」かを選ぶ(既定は法定休日の曜日から自動判定) |
| 会社休日への出勤 | 法定休日なら1.35倍。所定休日(法定超)なら通常の①②③ |
| 未入力日 | すでに過ぎた所定労働日のうち、打刻も指定も無い日。**理由を問わず一律**「所定内・残業なし」として1日の所定労働時間分を自動加算する |

未入力日はいつでも後から実際の時刻を追記でき、追記すると通常の勤務日として再計算される。
追記は必須ではなく、アプリからの催促・通知は一切行わない(出張などで最初から打刻するつもりが
ない日を想定)。

## 5. 打刻と自動モード

### 5.1 手動モード(既定)

状態は `off` / `working` の2つだけ。

- **出勤** — 現在時刻を記録し、その日が法定休日に当たるかを判定して保持する
- **退勤** — 打刻区間をカレンダーに確定保存し、前回退勤時刻を更新する
- 日をまたいだ勤務は出勤日の記録として保存し、翌日には「継続日」の印を付ける
  (その日が未入力日として二重に加算されないようにするため)
- 出勤したままブラウザを閉じても、次に開いたときに経過時間から計算し直す

### 5.2 自動モード

出勤/退勤ボタンを使わず、標準勤務スケジュールに沿って自動的に計測する。

| 状況 | 挙動 |
|---|---|
| 勤務予定時間内に開いた | 自動的にカウンターが動いている。ボタン操作は不要 |
| 休憩時間帯 | カウンターが止まる |
| 退勤予定時刻を迎えた | そのまま自動的に確定する |
| 残業する日 | 勤務中に小さく出ている「残業開始」を **退勤予定時刻の前に** 押しておくと自動確定しない。実際に終えたら「残業終了」で確定 |
| 有給・会社休日に指定した日 | カウンターは動かない |
| 所定労働日の曜日でない日 | カウンターは動かない |

内部的には「残業開始」= 退勤予定時刻での自動確定を無効化するフラグを立てるだけで、金額計算の
ロジックは手動モードとまったく同じものを使う。

予定と違う日(遅刻・早退・半休・出張)は、カレンダーからその日だけ実際の時刻に修正できる。

## 6. 集計と表示

### 6.1 今月の合計

```
実働合計時間 = Σ 打刻から確定した実働時間
             + Σ 有給の日の所定労働時間
             + Σ 未入力日の所定労働時間
```

締め日を過ぎるまでは「速報値(月途中)」として扱い、締め日まであと何日かを補助情報に表示する。

### 6.2 前月比較

月の途中で単純に合計を比べても先月が必ず多く見えるため、**同じ経過日数どうし** で比べる。

```
経過日数 N = 今日 − 清算期間の開始日 + 1
比較対象 = 先月の清算期間の開始日から N 日目までの実績
差 = 今月ここまで − 比較対象
```

プラスならポジティブな色で、マイナスでも責めるトーンにはしない。先月のデータが無い場合
(使い始めた最初の月)は表示しない。

### 6.3 36協定の目安

金額計算には一切影響しない参考情報。

- 月45時間(原則上限)・月60時間(割増率が変わるライン)までの残り
- 直近12ヶ月の法定時間外の累計、月45時間超の回数
- 直近2〜6ヶ月の平均

45時間・360時間の判定は法定時間外労働で行い、単月100時間・複数月平均80時間の判定には
法定休日労働も加える。正式な36協定の管理・届出は会社の勤怠システムが行うものである。

### 6.4 気づき表示

警告色・通知音・ポップアップは使わず、折りたたみの中に静かに置く。

- **休憩未取得の目安** — その日の実働が6時間(法定45分以上)・8時間(同60分以上)を超えているのに、
  休憩の自動控除が発生していない場合に表示する

## 7. 金額の見せ方

金額はぼかさず、常にそのまま表示する。設計当初は覗き見防止のぼかしを入れていたが、
**増えていく数字が見えないとモチベーションにならない**ため取りやめた(9章)。

設定画面の基本給の入力欄だけは伏せ字のままにしてある(右の「表示」ボタンで確認できる)。
金額そのものより桁が大きく、人前で設定を開いたときに目立つため。

## 8. データ保存

サーバーへは一切送信せず、その端末のブラウザ内(localStorage)にのみ保存する。家族それぞれが
自分の端末で開けば、それぞれ独立したデータになる(共有・同期はしない)。

| キー | 内容 |
|---|---|
| `wageSettings` | 3章の設定一式 |
| `wageState` | 出退勤の状態・出勤時刻・前回退勤時刻・自動モードの残業フラグ・現在の清算期間 |
| `wageCalendar` | 日付ごとの状態(打刻 / 有給 / 会社休日)。今月と先月ぶんのみ |
| `wageCurrentPeriodLog` | 進行中の清算期間の日別ログ |
| `wagePreviousPeriodLog` | 直前に確定した清算期間の日別ログ(前月比較に使用) |
| `wageOvertimeHistory` | 清算期間ごとの残業時間の合計だけを持つ軽量な配列(最大12ヶ月) |
| `wageTheme` | ライト / ダークの明示指定。未保存なら端末の設定に追従する |

### 8.1 締め日をまたいだときの処理

日別の詳細ログは今月と先月の2期間ぶんだけを保持する。締め日を迎えたら次の順で処理する。
**残業サマリーを履歴に追記してから、詳細ログを破棄する** 順序を必ず守る。

1. 終わった清算期間を確定させる(未入力日の自動加算も含めて確定)
2. その期間の残業時間の合計を `wageOvertimeHistory` に追記(13ヶ月目の古い分は削除)
3. その期間の日別ログを `wagePreviousPeriodLog` に移す
4. `wageCalendar` から、先月の開始日より前の日付を削除する
5. 新しい清算期間をゼロから開始する

数ヶ月ぶりに開いた場合も、間の各期間がそれぞれ履歴に残る。削除は自動で行い、確認や警告は出さない。

### 8.2 データが消える条件

以下のいずれかを行うと、保存されている設定・実績はすべて消える。復元手段はない。

- ブラウザの「閲覧履歴データを削除」「サイトデータを削除」等を行った
- シークレットモード / プライベートブラウジングで使っていた(タブを閉じた時点で消える)
- ブラウザアプリ自体をアンインストールした
- 端末を機種変更・初期化した(自動的な引き継ぎはない)
- 普段と違うブラウザや別の端末で開いた(ブラウザ+端末ごとに独立)
- ブラウザのストレージ容量が逼迫し、自動的にサイトデータが削除された
- ホーム画面に追加したアイコンを削除して入れ直した(再インストール扱いになることがある)

通常の再読み込み、ブラウザを閉じて開き直す操作、端末の再起動、オフラインでの使用では消えない。

## 9. 元の SPEC.md との違い

計算精度と使い勝手を優先して、次の6点は元の仕様の字面から変えている。いずれも定数か関数
1つで元に戻せる。

| # | 内容 | 理由 |
|---|---|---|
| 1 | 休憩の自動控除は「実際に重なった分」だけ | 字面は「重なっていれば時間帯の長さ」だが、13:00出勤でわずかに掛かる日などが過剰控除になるため。まるごと重なる通常の日は結果が同じ |
| 2 | 休憩時間帯が未登録のときの一律60分は、実働8時間かけて按分 | 出勤直後に60分まとめて引くと金額がマイナスから始まり、「開いた瞬間に増えている」体験が壊れるため。8時間以上働けば60分ちょうどで一致 |
| 3 | 法定休日労働を所定/法定の総枠・月60時間ラインに算入しない | 労基法上、休日労働は時間外労働に算入しない。算入すると平日の残業区分まで押し上がってしまうため |
| 4 | 設定に「所定労働日の曜日」を追加 | 総枠の計算に所定労働日数が必要で、毎月カレンダーで指定させるのは「操作は単純に」に反するため。自動モードの勤務予定曜日と共用 |
| 5 | **1日の所定労働時間は入力せず、勤務時間 − 休憩時間で自動算出** | 利用者の指摘。基本給・勤務時間・休憩時間を入れれば所定労働時間は決まるので、入力項目をひとつ減らせる |
| 6 | **覗き見防止のぼかしを廃止した** | 元の仕様は「常にオン・切り替えなし」。増えていく数字が見えないとモチベーションにならない(SPEC 1.1 の目的)という利用者の判断による |
| 7 | **勤務間インターバルの目安を廃止した** | 利用者の判断により、設定項目と表示の両方を削除 |
| 8 | 見た目を「カード基調の計器ダッシュボード + ライト/ダーク切替」にした | 利用者から提示されたデザイン見本に合わせた。元の仕様の LCD / 計器盤モチーフの意図(計器として読む)は引き継いでいる |

そのほか、時間外労働の端数処理(1ヶ月合計の30分未満切り捨て等)は元の仕様どおり適用せず、
実数のまま表示・積算する。

## 10. 対象外・免責

- **非対象**: 社会保険料・所得税・住民税などの控除計算、年末調整、賞与計算。額面(グロス)の
  労働対価のみを可視化する
- **打刻は会社の勤怠システムとは別物**。表示される金額は体感用の目安であり、給与明細と一致しない
  ことは仕様として許容する
- 本アプリは一般的に用いられる計算方法の実装であり、法律相談・労務相談・正式な給与計算の
  代替ではない。実際の運用では会社の就業規則・36協定の内容が優先される

## 11. 技術構成とテスト

フレームワーク・ビルド・依存パッケージなし。`index.html` を `file://` で直接開いても動くよう、
ES モジュールではなく素の `<script>` 分割 + `WT` 名前空間で構成している。

| ファイル | 役割 |
|---|---|
| `src/constants.js` | 割増率・深夜帯・36協定の目安・既定設定値 |
| `src/time.js` | 日付/時刻、深夜帯の分割、休憩帯の差し引き |
| `src/period.js` | 締め日から清算期間を算出 |
| `src/wage.js` | 基礎時給単価、休憩控除、区分計算 |
| `src/aggregate.js` | 期間集計、有給・会社休日・未入力日、前月比較、36協定、気づき |
| `src/storage.js` | localStorage、締め日のロールオーバー、自動モードの状態解決 |
| `src/app.js` | DOM 層(描画ループ・ゲージ・操作・設定/カレンダー・テーマ) |

`src/app.js` 以外は DOM に依存しない純粋関数の層。重い区分計算は1秒ごと、金額の描画は
`requestAnimationFrame` に分離しており、区分計算が重くなっても数字の動きは滑らかなまま保たれる。
